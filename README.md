# Laptop Hub

Premium, responsive landing page MVP for a laptop technology store — built with **React** and **Vite**.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 18 (functional components, JavaScript)
- Vite 6
- CSS (custom properties, no Tailwind)
- [react-icons](https://react-icons.github.io/react-icons/)

## Project structure

- `src/data/` — sample laptops, accessories, and services
- `src/components/` — reusable UI sections
- `src/styles/global.css` — design tokens and shared styles
